The files in extracted-source/ were received via email from Gunther Schmidl
on 2026-09-18. He extracted them using the script in this top-level directory,
which was produced with help from an LLM. You can reproduce them this way:

    rm -rf extracted-source/
    python extract-from-ulb.py original-files/adv.ulb extracted-source

The Pascal files are internally dated by code comments, all ranging
from 17-SEP-80 to 12-NOV-80, except for VERBS2.PAS (26-MAY-81) and
TRAVEL.PAS (29-OCT-81).
