The files in original-files/ were downloaded on 2026-09-21 from
https://www.ibiblio.org/pub/academic/computer-science/history/pdp-11/rsx/decus/rsx82b/351130/
They were all originally timestamped 1983-04-06.

For the original README, see original-files/readme.1st

The files in extracted-source/ were received via email from Gunther Schmidl
on 2026-09-18. He, with some help from an LLM, extracted them from ADV.ULB
in the manner originally intended by Barry Breen: using ADVPRT.CMD to print
a source listing. I don't yet know a proper way to reproduce this feat,
so I'm just trusting that these are in fact the Pascal files as extracted.

The Pascal files are internally dated by code comments, all ranging
from 17-SEP-80 to 12-NOV-80, except for VERBS2.PAS (26-MAY-81) and
TRAVEL.PAS (29-OCT-81).
