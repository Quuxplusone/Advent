To run the game, you'll need the Atari800 emulator, available at
    https://github.com/atari800/atari800
or (on Mac OSX) by running `brew install atari800`. Then run:

    atari800 -win-width 1280 -win-height 960 -atari -basic HOWE0301.atr

    Robert A. Howell's "Adventure!" (1982) for Atari.
    A port of Crowther & Woods' Colossal Cave Adventure.
    ("HOWE0301" in Culver's nomenclature.)

    The game is basically Crowther & Woods' Adventure, except:

    The "all different" maze doesn't actually have different room descriptions.
    Aboveground is four rooms with identical descriptions, mazily connected.
    Depositing all 15 treasures (and delivering the magazines) gives 281 points;
    it's not clear how to get the last 20 points and/or win the game.
